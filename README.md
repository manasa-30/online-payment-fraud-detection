# Online Payment Fraud Detection

An intelligent machine learning project that detects fraudulent online payment transactions using data analysis and classification algorithms. This system helps identify suspicious transactions and improves the security of digital payment systems by predicting fraud in real time.

---

## 🚀 Project Overview

With the rapid growth of online transactions, payment fraud has become a major cybersecurity and financial challenge. This project focuses on building a fraud detection model using machine learning techniques to classify transactions as **fraudulent** or **legitimate** based on transaction details and behavioral patterns.

The project includes:
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training and evaluation
- Fraud prediction using machine learning algorithms

---

## 🛠️ Technologies Used

- Python
- Jupyter Notebook

- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📂 Dataset Features

The dataset contains transaction-related attributes such as:
- Transaction type
- Transaction amount
- Sender and receiver balances
- Old and new account balances
- Fraud labels

These features help the model learn transaction behavior patterns and identify anomalies.

---

## 🤖 Machine Learning Algorithms

The following algorithms were used for fraud detection:
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

Among these, Random Forest achieved better accuracy and performance in detecting fraudulent transactions.

---

## 📊 Project Workflow

1. Import and preprocess the dataset
2. Handle missing and inconsistent values
3. Perform Exploratory Data Analysis (EDA)
4. Train machine learning models
5. Evaluate model performance
6. Predict fraudulent transactions

---

## 📈 Model Evaluation Metrics

The models were evaluated using:
- Accuracy Score
- Precision
- Recall
- F1-Score
- Confusion Matrix

These metrics help measure how effectively the model identifies fraud while minimizing false predictions.
